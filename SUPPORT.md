# Support

| I want to… | Go to |
|---|---|
| ask how to do something, show what I built | [GitHub Discussions](https://github.com/pardesline/pardesline/discussions) (Q&A, Show and tell) |
| report a bug | [New issue → Bug report](https://github.com/pardesline/pardesline/issues/new?template=bug_report.yml) |
| request a dataset, an algorithm or a model | [New issue → Dataset request / Algorithm or model request](https://github.com/pardesline/pardesline/issues/new/choose) |
| report a security problem | [SECURITY.md](SECURITY.md): private vulnerability reporting, not a public issue |
| read the documentation | <https://pardesline.github.io/pardesline/> |
| contribute | [CONTRIBUTING.md](CONTRIBUTING.md), then a [good first issue](https://github.com/pardesline/pardesline/issues?q=is%3Aissue+is%3Aopen+label%3A%22good+first+issue%22) |

Before asking, run `pardesline version` and `pardesline datasets` and include their output; for a bug, the full log (`PARDESLINE_LOG=DEBUG`) and the smallest snippet that reproduces it. Maintainers answer on GitHub; there is no private support channel for the open-source package.
