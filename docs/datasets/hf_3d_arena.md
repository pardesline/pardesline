# 3D Arena: image-to-3D outputs of 29 generators on 100 shared input images

`pl.load("hf_3d_arena")` loads this dataset. The benchmark behind the 3D Arena Space: for each of ~100 input images (inputs/images, from the iso3D dataset) the output of 29 image-to-3D models under outputs/<model>/<image>.glb|.ply with a rendered preview .png. Meshes are glTF (Y-up, metres by spec, scale is the generator's own); the .ply outputs of the Gaussian-splat generators (SAM-3D-Objects-3DGS) are splats. A sample is one (model, image) pair.

```python
import pardesline as pl

ds = pl.load("hf_3d_arena")
print(ds.describe())  # roles, frames, units, labels, licence, citation
s = ds[0]
obj = s.mesh  # fetched now, cached under ~/.cache/pardesline/datasets/hf_3d_arena
```

## Standardized layout

Files are fetched on first access into the dataset cache and stay in their original format; `ds.export(folder)` writes every sample as standard files (PLY for points and meshes, MetaImage for volumes and label maps) with a `.pardesline.json` sidecar carrying frame, units, labels, licence and provenance, plus a manifest for the folder. Label maps become exact surfaces with `to_mesh(label=k)`, DICOM series become one volume, raw arrays are decoded through the layout above.

```python
ds = pl.load("hf_3d_arena").take(2)
ds.export("./standardized")        # PLY / MetaImage + sidecars + manifest.json
```
