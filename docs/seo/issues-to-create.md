## Tracking issues (`roadmap`)

### Model registry: one-line access to pretrained 3D and medical models
Labels: `roadmap`, `model`
Vote with 👍. Models get the same treatment as datasets: a **model manifest** (source, weights URI, licence, input type, task, memory / GPU needs, provenance, citation) and one loader / runner API whatever the source (Hugging Face Hub, torch.hub, vendor repositories): `model = pl.load_model("dinov3")`, `out = pl.run(model, dataset)`, then visualise. Candidates: DINOv3 / DINOv2 (features), SAM-3D-style segmenters, 3D JEPA encoders, PointNet / PointNet++, nnU-Net and TotalSegmentator-class segmentation nets. Today: reference scripts in the skills and the `/models/<name>/` docs pages, which keep their URLs. Manifests can be contributed now from `templates/new_model/` (see "Models wanted"). Design questions to settle here: manifest schema, weight caching, preprocessing contract (`Volume` to tensor and back), licence gating, GPU detection.

### Gaussian splats as a first-class kind
Labels: `roadmap`, `enhancement`
A `Splat` object (`kind = "splat"`): load 3DGS PLY and `.npy` layouts (KITTI-360 GS, C3VD), `to_points()`, render a preview, metrics against a point cloud, save with sidecar. Datasets already bundled: `c3vd_endoscopy_splats`, `hf_kitti360_gs_subset`, `hf_3d_arena`. Reference: `skills/gaussian-splatting/scripts/points_to_gaussians.py`.

### Benchmarks: package defaults vs upstream defaults, regenerated by CI
Labels: `roadmap`
`benchmarks/` has registration and Poisson reconstruction on the bunny. Wanted: volume rigid registration (RIRE, `simpleitk_registration.rigid` vs a plain SimpleITK call), threshold + components segmentation (MSD spleen), outlier removal, LiDAR ground removal (KITTI); a nightly workflow that runs them and commits `benchmarks/results.md` when numbers move.

### A pardesline organisation on Hugging Face mirroring the permissive datasets
Labels: `roadmap`, `dataset`
For CC0 / CC BY / PDDL sources only: mirrors with dataset cards that document `pip install pardesline` and `pl.load("name")` as the loader, a Space running the README demo. Needs the organisation, a licence check per dataset, and a sync script.

### Deformable registration and learned segmentation behind the same calls
Labels: `roadmap`, `algorithm`
`align(mode="deformable")` routing to CPD (points) or B-spline / demons (volumes) after the rigid stage; `segment(model="totalsegmentator")` once the model registry exists. Keep the sidecar contract: every parameter recorded.

### Datasets wanted
Labels: `dataset`, `good first issue`
One comment per candidate with the source and the licence; each becomes its own issue when someone takes it. Seed list: BraTS (Synapse DUA: a loader with the user's credentials), VerSe 2020, MSD-adjacent challenge sets (FLARE, WORD), ACDC cardiac MRI, Learn2Reg pairs, the remaining public TCIA collections with segmentations, ModelNet40 / ShapeNetCore (registration-gated), ScanNet (agreement), nuScenes mini, Waymo open (terms), SemanticKITTI, MedShapeNet per-structure subsets, OpenNeuro datasets by id. Template: `templates/new_dataset/`.

### Models wanted
Labels: `model`, `good first issue`
One comment per model with weights URI, licence, input / output types, runtime needs; a manifest from `templates/new_model/` is the contribution. Seed list: TotalSegmentator (CT, MRI), nnU-Net MSD task models, DINOv2 (open) and DINOv3 (gated) backbones, SAM 2 / MedSAM for 2D slices, PointNet++ ModelNet weights, VISTA-3D (NIM licence check), Segment Anything in 3D variants, MONAI Model Zoo bundles (spleen, lung nodule).

### Real cases wanted
Labels: `real-case`, `help wanted`
Reproducible runs on production-like data for `examples/real_cases/`: industrial structured-light or laser scans (partial, noisy), de-identified CT / MR volumes with unusual spacing, field LiDAR. Data under a redistributable licence or behind a loader to the owner's server. Template and review rules in `examples/real_cases/README.md`.
